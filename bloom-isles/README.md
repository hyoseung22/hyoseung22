# Bloom Isles

랜덤으로 생성된 섬을 받아 봇 3명과 경쟁하며 가장 풍요로운 섬을 만드는 데스크톱 게임입니다. [Bevy](https://bevyengine.org) 0.16 엔진(Rust)으로 만들었고, 설명 텍스트 없이 그림과 아이콘만으로 진행됩니다.

실행 파일 하나로 동작합니다. 그림은 시작할 때 벡터로 그려서 텍스처로 만들고, 효과음과 배경음은 코드로 합성하고, 폰트는 실행 파일에 포함되어 있어서 별도의 에셋 폴더가 필요 없습니다.

## 실행 파일 받기

저장소의 **Actions → Bloom Isles builds** 워크플로가 푸시할 때마다 Windows, macOS, Linux용 실행 파일을 빌드합니다. 실행 결과 페이지 아래쪽 **Artifacts**에서 `bloom-isles-windows` 등을 내려받으면 됩니다.

## 직접 빌드

1. [rustup](https://rustup.rs)으로 Rust를 설치합니다(1.85 이상).
2. Linux에서는 시스템 라이브러리가 필요합니다.
   ```sh
   sudo apt-get install libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev
   ```
3. 빌드하고 실행합니다. 첫 빌드는 엔진을 컴파일하느라 몇 분 걸립니다.
   ```sh
   cd bloom-isles
   cargo run --release
   ```
   실행 파일은 `target/release/bloom-isles`(Windows는 `bloom-isles.exe`)에 생깁니다.

게임 규칙 테스트는 `cargo test --release`로 돌립니다. 섬 생성 검사와 봇끼리 한 판을 끝까지 두는 밸런스 검사가 들어 있습니다.

## 플레이

- **타이틀**: 주사위로 내 섬을 다시 뽑고, 새싹 1~3개로 난이도를 고른 뒤 재생 버튼을 누릅니다.
- **배치**: 카드를 타일로 드래그하거나, 카드를 누른 뒤 타일을 누릅니다. 카드를 들면 타일마다 그 자리에서의 기분이 점으로 보입니다(초록 = 번성, 노랑 = 보통, 빨강 = 슬픔). 타일 위에 올리면 하트 선(서로 도움)과 회색 깨진 하트(서로 싫어함)가 나타납니다.
- **생태계**: 번성하는 생물은 새 생명을 퍼뜨립니다. 벌은 꽃을, 새는 덤불과 나무를, 개구리는 연잎을, 나무는 버섯을 늘립니다. 슬픈 상태가 오래 이어지면 시들거나 섬을 떠납니다. 배치된 생물을 누르면 누구와 어떤 관계인지 보여 줍니다.
- **방해**: 폭풍이나 딱정벌레 카드를 오른쪽의 상대 섬 패널에 떨어뜨립니다. 패널을 눌러 상대 섬을 보고 있을 때는 폭풍을 원하는 타일에 떨어뜨릴 수 있습니다.
- **방어**: 먹구름은 여러 번 눌러 날려 보내고, 딱정벌레는 눌러서 잡습니다. 유리 돔 카드는 잠시 동안 섬을 보호합니다.
- **승리**: 상단 트랙 끝의 꽃에 먼저 도착한 섬이 이깁니다. 해 모양 타이머(5분)가 끝나면 가장 풍요로운 섬이 이깁니다.

| 조작 | |
|---|---|
| 원형 화살표 버튼 | 손패 전체 다시 뽑기 |
| 삽 버튼 | 배치한 것 파내기 |
| 집 버튼 | 상대 섬을 보다가 내 섬으로 돌아가기 |
| 1–4 | 카드 선택 |
| Esc | 선택 취소 / 일시정지, 타이틀에서는 종료 |

난이도, 음소거, 튜토리얼 진행 상황은 `%APPDATA%\BloomIsles\settings.txt`(Windows) 또는 `~/.local/share/BloomIsles/settings.txt`에 저장됩니다.

## 코드 구조

| 파일 | 내용 |
|---|---|
| `src/island.rs` | 육각 타일 섬 생성 |
| `src/eco.rs` | 종 정의와 관계 |
| `src/sim.rs` | 게임 규칙: 행복도, 점수, 카드, 폭풍과 딱정벌레, 봇 AI (엔진과 무관, 테스트 포함) |
| `src/art.rs` | 모든 그림을 tiny-skia 벡터로 그려 텍스처로 만듦 |
| `src/audio.rs` | 효과음과 음표를 WAV로 합성 |
| `src/world.rs` | 카메라(메인 뷰 + 상대 섬 패널용 실시간 카메라 4대), 섬·생물·파티클 스프라이트 |
| `src/hud.rs` | 레이아웃, HUD, 타이틀·일시정지·결과 화면, 튜토리얼 손가락 |
| `src/input.rs` | 마우스, 터치, 키보드 |
| `src/shots.rs` | 개발용: `BLOOM_SHOTS=<폴더>`로 실행하면 화면별 스크린샷을 찍고 종료 |

타이틀 폰트는 Baloo 2이며 SIL Open Font License를 따릅니다(`assets/fonts/OFL.txt`).
