# Bloom Isles

랜덤으로 생성된 섬을 받아, 봇 3명과 경쟁하며 가장 풍요로운 섬을 만드는 브라우저 게임입니다. 설명 텍스트 없이 그림과 아이콘만으로 진행됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요 없습니다.

## 플레이

- **배치**: 카드를 타일로 드래그하거나, 카드를 누른 뒤 타일을 누릅니다. 타일의 점은 그 자리에서의 기분을 미리 보여줍니다(초록 = 번성, 노랑 = 보통, 빨강 = 슬픔). 하트 선은 서로 돕는 관계, 회색 깨진 하트는 서로 싫어하는 관계입니다.
- **생태계**: 번성하는 생물은 새 생명을 퍼뜨립니다. 벌은 꽃을, 새는 덤불과 나무를, 개구리는 연잎을, 나무는 버섯을 늘립니다. 슬픈 상태가 오래 이어지면 시들거나 떠납니다.
- **방해**: 폭풍 카드나 딱정벌레 카드를 상대 섬 패널에 떨어뜨립니다. 상대 섬을 보고 있을 때는 원하는 타일을 직접 노릴 수 있습니다.
- **방어**: 먹구름은 여러 번 눌러 날려 보내고, 딱정벌레는 눌러서 잡습니다. 유리 돔 카드는 잠시 동안 섬을 보호합니다.
- **승리**: 상단 트랙 끝의 꽃에 먼저 도착한 섬이 이깁니다. 해 모양 타이머가 끝나면 가장 풍요로운 섬이 이깁니다.
