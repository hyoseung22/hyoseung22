# Bloom Isles

랜덤으로 생성된 섬을 받아, 해가 지기 전(10분)까지 동식물과 환경을 가꿔 가장 멋진 섬을 만드는 데스크톱 게임입니다. 결과는 별 1~3개로 매겨집니다. [Bevy](https://bevyengine.org) 0.16 엔진(Rust)으로 만들었고, 설명 텍스트 없이 그림과 아이콘만으로 진행됩니다.

아트는 로우폴리 3D 보드게임 스타일입니다. 모든 모델은 실행할 때 기본 도형으로 조립합니다. 면마다 단색에 빛 방향 음영을 구워 넣고, 굵고 진한 외곽선(부풀린 뒷면 셸)을 둘렀습니다. 동물은 나무 받침대 위의 말이고, 섬은 육각 보드 타일입니다. 카메라는 보드게임을 내려다보는 각도의 정사영 카메라이고, 카드와 폰 아이콘도 같은 3D 모델을 텍스처로 렌더해서 씁니다.

실행 파일 하나로 동작합니다. 그림은 시작할 때 벡터로 그려서 텍스처로 만들고, 효과음과 배경음은 코드로 합성하고, 폰트는 실행 파일에 포함되어 있어서 별도의 에셋 폴더가 필요 없습니다.

## 실행 파일 받기

저장소의 **Actions → Bloom Isles builds** 워크플로가 푸시할 때마다 Windows, macOS, Linux용 실행 파일을 빌드합니다. 실행 결과 페이지 아래쪽 **Artifacts**에서 `bloom-isles-windows` 등을 내려받으면 됩니다.

## 직접 빌드

1. [rustup](https://rustup.rs)으로 Rust를 설치합니다(1.85 이상).
2. Linux에서는 시스템 라이브러리가 필요합니다.
   ```sh
   sudo apt-get install libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev
   ```
3. 빌드하고 실행합니다. 첫 빌드는 엔진을 컴파일하느라 몇 분 걸립니다.
   ```sh
   cd bloom-isles
   cargo run --release
   ```
   실행 파일은 `target/release/bloom-isles`(Windows는 `bloom-isles.exe`)에 생깁니다.

리소스를 파일로 내보내려면 `bloom-isles --export <폴더>`를 실행합니다. 3D 모델(OBJ, 정점 색 포함), UI 이미지(PNG), 효과음과 음악(WAV)이 저장됩니다.

게임 규칙 테스트는 `cargo test --release`로 돌립니다. 섬 생성 검사, 자동 플레이로 한 판을 끝까지 두는 별 밸런스 검사, 동물 이동과 섬 성장 검사, 바이옴별 적응·이주·토착종 검사, 합성 사운드 검사가 들어 있습니다.

## 플레이

- **타이틀**: 주사위로 내 섬을 다시 뽑고, 새싹 1~3개로 난이도를 고른 뒤 재생 버튼을 누릅니다. 새싹이 많을수록 딱정벌레 떼와 먹구름 같은 자연재해가 자주 옵니다(새싹 1개는 재해 없음). 최고 기록(별과 점수)도 타이틀에 보입니다.
- **템포**: Stacklands처럼 느긋하게 흘러갑니다. 카드는 덱에서 한 장씩 천천히 나눠지고(11초에 한 장), 놓은 말은 판 위로 천천히 내려앉으며, 동물은 느긋하게 한 칸씩 옮겨 다니며, 날씨와 지형 변화도 길게 이어집니다. 오른쪽 위 화살표 버튼(또는 Tab)으로 2배속, 스페이스바로 언제든 멈추고 다시 시작할 수 있습니다.
- **목표**: 상단 막대가 차오르며 별 3개를 향해 갑니다. 별에 닿을 때마다 종소리와 관중 환호가 터집니다. 해 모양 타이머가 다 돌면 결과 발표입니다.
- **배치**: 카드를 타일로 드래그하거나, 카드를 누른 뒤 타일을 누릅니다. 카드 아래 육각 칩은 살 수 있는 땅입니다. 카드를 들면 타일마다 그 자리에서의 기분이 점으로 보입니다(초록 = 번성, 노랑 = 보통, 빨강 = 슬픔). 타일 위에 올리면 하트 선(서로 도움)과 깨진 하트(서로 싫어함)가 나타납니다.
- **도감**: 오른쪽 패널에 동식물 23종과 환경 4종이 있습니다. 섬에 처음 나타난 종은 실루엣에서 색이 켜지며 "띵!" 하고, 지금 번성 중인 종에는 금빛 원이 돕니다. 다양한 종이 번성할수록 점수가 커집니다.
- **환경 카드(바이옴)**: 가끔 금빛으로 빛나는 특별 카드가 나옵니다. 타일에 놓으면 그 타일과 주변 6칸이 새로운 환경으로 바뀝니다.
  - **화산**: 가운데에 화산, 주변은 뜨겁고 기름진 화산재. 불꽃풀과 도마뱀이 찾아옵니다. 가끔 분화해서 땅을 흔들고, 주변을 비옥하게 하고, 화산재를 더 멀리 뿌립니다. 더위를 못 견디는 동물은 도망칩니다.
  - **대호수**: 깊은 호수. 물고기, 갈대, 오리가 찾아옵니다. 비가 오면 옆 연못을 삼키고 가뭄이면 가장자리가 줄어듭니다.
  - **설산**: 가운데에 눈 덮인 산, 주변은 눈밭. 전나무와 산양이 찾아옵니다. 비가 오면 눈이 넓어지고 가뭄이면 먼 눈밭이 녹아 풀밭이 됩니다.
  - **사막**: 주황 모래언덕. 선인장, 낙타, 도마뱀이 찾아옵니다. 가뭄에는 사막이 번지고, 비가 오면 물가부터 다시 풀이 돋습니다.
  - 카드를 든 채 타일 위에 올리면 바뀔 범위가 금색으로 표시되고, 거기 사는 생물의 운명이 아이콘으로 보입니다: 하트(그대로 삶), 반짝이(적응할 수 있음), 깨진 하트(시듦), 발자국(다른 곳으로 이사).
- **적응과 이주**: 땅이 바뀌면 식물은 그 환경에 맞는 사촌으로 변하거나(나무 → 전나무, 꽃 → 갈대, 덤불 → 선인장·불꽃풀) 적응하지 못하면 시듭니다. 건강한 식물일수록 적응 확률이 높습니다. 동물은 살 수 있는 가장 가까운 곳으로 크게 뛰어 이사하고, 갈 곳이 없으면 섬을 떠납니다. 화산 분화, 눈, 사막 확장처럼 저절로 일어나는 변화에도 똑같이 반응합니다.
- **생태계**: 번성하는 생물은 새 생명을 퍼뜨립니다. 벌은 꽃과 불꽃풀을, 새는 덤불·나무·전나무를, 개구리는 연잎과 갈대를, 나무는 버섯과 고사리를 늘립니다. 슬픈 상태가 오래 이어지면 시들거나 섬을 떠납니다. 배치된 생물을 누르면 누구와 어떤 관계인지 보여 줍니다.
- **자연재해**: 딱정벌레 떼는 눌러서 잡고, 먹구름은 여러 번 눌러 날려 보냅니다. 개구리, 새, 게, 오리, 도마뱀은 딱정벌레를 잡아먹는 자연 방어선입니다.
- **보드게임 말**: 동물은 받침대 위의 말입니다. 몇 초마다 이웃 타일을 살펴보고, 더 살기 좋은 곳이 있으면 톡 튀어 이동합니다.
- **섬이 자란다**: 점수가 일정 수준을 넘을 때마다 바다에서 새 땅이 솟아오르고, 관중이 "와우~" 하고 환호합니다.
- **콤보**: 좋은 자리에 연달아 놓으면 x2, x3… 콤보가 쌓입니다. 3콤보부터는 빈 카드가 빨리 채워집니다.
- **메가 블룸**: 식물을 심으면 가끔 주변에 같은 식물이 한꺼번에 피어납니다.
- **황금 고래**: 가끔 섬 옆에 황금 고래가 떠오릅니다. 사라지기 전에 누르면 보물로 생물 3마리가 생깁니다.
- **파티**: 일정 점수마다 섬의 모든 말이 함께 뛰어오릅니다.
- **결과 발표**: 드럼롤과 함께 점수가 올라가고, 별이 하나씩 판정됩니다. 별마다 관중의 박수가 커지고, 별 2개부터 폭죽, 별 3개면 색종이까지 쏟아집니다. 최고 기록을 넘으면 왕관과 팡파르가 나옵니다. 이번 판에 모은 종도 한 줄로 보여 줍니다.
- **환경**: 타일마다 **수분**과 **비옥도**가 있습니다.
  - 수분은 물 근처, 나무 그늘, 눈밭 옆, 비가 올 때 높아지고, 화산 옆에서는 낮아집니다. 비옥도는 동물이 지나다니고 생물이 죽어 흙으로 돌아가면 올라가고, 식물이 자라면 줄어듭니다.
  - 나무, 전나무, 야자수는 이웃 타일에 **그늘**을 만듭니다. 섬 바닥 색이 젖은 흙, 마른 풀, 기름진 땅으로 변해서 상태가 보입니다.
  - 화산 옆은 **덥고**, 눈밭과 설산 옆은 **춥습니다**. 더위를 좋아하는 종(선인장, 불꽃풀, 도마뱀, 낙타, 야자수)과 추위를 좋아하는 종(전나무, 산양, 여우, 토끼, 사슴)이 따로 있습니다.
- **날씨**: 맑음, 비, 가뭄, 바람이 돌아가며 섬에 영향을 줍니다. 타이머 옆 아이콘에 지금 날씨와 다음 날씨 예보가 나옵니다.
  - 비: 땅이 젖고 개구리와 오리가 신나며 벌은 쉽니다. 딱정벌레가 씻겨 나가고, 물가가 넘쳐 연못이 생깁니다. 설산 주변에 눈이 쌓이고 사막 물가가 푸르러집니다.
  - 가뭄: 꽃과 개구리가 힘들어하고 연못과 호수 가장자리가 마릅니다. 사막이 번지고 눈이 녹습니다. 선인장과 도마뱀은 좋아합니다.
  - 바람: 씨앗이 멀리 날아가 식물이 더 잘 퍼지고, 벌과 새는 날기 힘들어합니다.
- **생물끼리 하는 일** (선과 아이콘으로 보입니다):
  - 벌이 꽃, 덤불, 불꽃풀, 선인장을 **수분**시킵니다. 수분된 식물은 더 잘 퍼지고, 덤불에는 열매가 열립니다.
  - 토끼, 사슴, 산양(가시 선인장까지!), 오리는 식물을 **뜯어 먹습니다**.
  - 배고픈 여우는 토끼와 오리를 **사냥**합니다. 덤불, 나무, 전나무, 갈대 근처에 있으면 더 잘 도망칩니다("!").
  - 새는 열매를 먹고 나중에 다른 곳에 **씨앗**을 떨어뜨립니다. 배고픈 새는 호수의 물고기를 낚아챕니다.
  - 낙타는 두 칸 안에 물이 있으면 **물을 마시고**, 없으면 선인장을 씹습니다.
  - 물고기는 연잎과 갈대 사이에서 배를 채우고, 도마뱀은 햇볕 드는 돌·모래·화산재 위에서 기운을 차립니다.
  - 개구리, 새, 게, 오리, 도마뱀은 **딱정벌레를 잡아먹습니다**. 배고픈 개구리와 도마뱀은 벌도 먹습니다.
  - 생물이 죽으면 흙이 기름지고, 가끔 그 자리에 **버섯**이 돋습니다. 근처 게가 배를 채웁니다.
  - 벼락이 칠 때 나무가 있으면 **피뢰침**이 되어 주변을 지킵니다.
- **배고픔**: 동물은 시간이 지나면 배가 고파집니다. 잘 먹은 동물은 행복하고, 오래 굶은 동물은 섬을 떠납니다.

## 코드 구조

| 파일 | 내용 |
|---|---|
| `src/island.rs` | 육각 타일 섬 생성 |
| `src/eco.rs` | 종 정의와 관계, 바이옴과 토착종, 적응 규칙 |
